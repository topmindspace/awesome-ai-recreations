## 2026-11-14 复核

环境：Google Chrome 157.0.8103.50（headless），playwright-core 1.55.1，SwiftShader WebGL。页面目录为 `cases/oc8/models/workbuddy`。

- 本地 http 与 `file://` 都加载了 `index.html` 和 `film.html`。控制台没有 error，页面自己的请求没有 4xx/5xx。复核开始时，http 页面会让浏览器向站点根请求 `/favicon.ico` 并得到 404；`index.html` 增加空图标声明后，`node src/build.mjs` 重新生成 `film.html`，该请求不再出现。

- `film.html` 有 `FILM · AUTO TOUR 25s`。仿真时钟到 `00:03` 后进入拆解，到 `00:07` 后线框同时打开。`file://` 下同样在 `00:03` 进入拆解。headless 里主循环把每帧时间限制在 0.05 秒，帧率低时仿真时钟慢于墙钟；这是原有的 `dt` 上限，两个页面都已画出模型。
- 连续两次 `node src/build.mjs` 的 `film.html` 字节相同。`node src/check.mjs` 通过。
- 已发布的 GitHub Pages 从 `main` 根目录提供文件，没有单独的页面构建工作流。复核时两个地址都是 HTTP 200，Last-Modified 为 2026-11-14 12:14:07 GMT，对应已合入的 `ff08ba3`。同一版 headless Chrome 打开线上互动页和巡览页，画布为 1280×720，能看到机械章鱼，巡览页带有 `AUTO TOUR`。线上控制台唯一的 error 是 `/favicon.ico` 404；这次的空图标声明还没发布到线上。
