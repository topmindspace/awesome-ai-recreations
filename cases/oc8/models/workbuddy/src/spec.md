# WorkBuddy 版 · 实现规格与改编项

## 总体

- 单页应用：`index.html`（HUD/样式）+ `src/main.js`（全部三维逻辑）+ `lib/three.min.js`（r148 UMD）。
- 场景为浅色影棚（原作同为浅色背景），白装甲 + 黑关节 + 橙色点缀三色板。
- 网格总量约 944；全部程序化几何，无外部模型、贴图。

## 结构

- **花瓣壳 ×8**：郁金香铰链——铰点放在环圈上，几何平移至铰点局部坐标，开合旋转与方位旋转分离，避免欧拉角冲突。
- **缆线脑核**：头部球壳内缆线束 + 核心体，随心跳脉动。
- **腕足 ×8**：各 25 节链式关节，最大弯折 265°，相位差 1/8 周期卷曲律动，1.8Hz 心跳驱动。
- **拆解**：有序分解视图，各部件按部位分类做延迟插值位移；非随机爆散。

## 相对原作的重诠释项

- HUD 版式：顶部加载条/遥测面板为执行者设计，非逐像素对照原作界面。
- 原作约 25 秒的切镜编排未复现；本版为自由环绕 + 手动三态切换。
- 帧间不可见结构（内部传动等）由执行者推断，未标注估算尺寸明细。

## 音效

WebAudio 合成伺服嗡鸣与心跳低频，无音频文件。
